# Research Note 0004：时间序列切分与反未来函数

## 本篇问题

为什么量化研究不能随机切分 A 股日频样本？本篇把时间切分、标签可见性和隔离窗口写成一组可复核的研究约束。

## 数据范围与截止日期

本篇讨论公开基线中的日频横截面研究，不依赖实时行情，也不发布收益结果。复现实验应记录：

- 数据源和接口版本
- 数据拉取时间与数据截止日期
- 股票池及其生效日期
- 复权口径
- 特征、标签和交易执行的时间定义

任何在截止日期之后才出现的信息，都不能进入该日期的特征或股票池。

## 方法

公开基线采用按时间排列的训练、验证、测试和隔离窗口。一个最小的滚动结构可以表示为：

1. 训练窗口：只使用较早日期的特征和已经结束的标签。
2. 验证窗口：用于选择参数、阈值或早停条件。
3. 测试窗口：在参数冻结后评估一次。
4. 隔离窗口：在测试和下一次调参之间保留时间间隔，避免标签重叠和信息回流。

每次滚动向前推进时，只增加当时已经可见的数据。不能因为后续拿到了修订后的历史文件，就把旧实验的输入静默替换。

## 时间切分

随机切分会破坏时间顺序：相邻日期的样本可能同时出现在训练和测试中，未来市场状态、公司状态或标签信息就可能间接进入过去决策。

应至少检查：

- 训练集最大特征日期早于验证集和测试集起点。
- 训练标签的结束日期不超过训练数据可见边界。
- 测试窗口不参与参数选择、阈值调整或策略规则修改。
- 滚动窗口之间的隔离期足够覆盖标签持有期、数据发布延迟和执行延迟。
- 点时股票池、行业映射和公司状态都按生效日期截取。
- 使用后复权数据做特征时，不能把未来复权因子当成当日可见信息。
- 成交价格仍按未复权口径和 T+1 执行约束处理。

## 交易成本与执行假设

切分本身不等于可交易性验证。信号在 T 日收盘后生成时，最早只能在 T+1 的允许价格成交。研究记录还应明确：

- 佣金、印花税、过户费和滑点
- 涨跌停、停牌、T+1 和整数手限制
- 无法成交时的处理
- 成交价格和估值价格的区别

如果一个结果只有在用 T 日收盘价立即成交时才成立，它不能被当作符合公开基线执行口径的结果。

## 反未来函数检查

建议把检查做成失败项，而不是只在文章中口头说明：

- 给每个特征记录最大输入日期。
- 给每个标签记录开始日期和结束日期。
- 给每个股票池和行业字段记录生效区间。
- 在训练前检查特征、标签和执行窗口的日期关系。
- 对参数选择记录使用的窗口，确认没有读取测试结果。
- 对数据修订保留 revision，不覆盖原始实验的输入和报告。
- 在合成数据中加入一个带有明显未来信息的对照特征，确认时间切分检查能拒绝它。

这些检查仍不能证明不存在所有未来函数，但可以把常见泄漏变成可审计、可定位的失败。

## 失败实验或已知限制

一个常见失败实验是随机拆分，然后发现离线指标看起来稳定。这个结果不能说明模型有预测能力，因为相邻日期和重叠标签让测试集不再代表真正的未来。

另一个失败做法是先查看完整测试区间，再据此选择模型、持仓数量或交易成本参数。即使最终只报告一次测试结果，这也已经把测试集用于调参。

时间切分也不能解决数据源错误、幸存者偏差、股票池回填、复权口径错误或执行不可行等问题。它只是研究可信度的必要条件，不是充分条件。

## 如何复现

不需要 API 密钥即可运行公开基线的离线检查：

~~~bash
python -m pytest tests/test_splits.py tests/test_dataset_scoping.py -q
~~~

如果扩展切分逻辑，应同时增加边界测试：标签跨越窗口、隔离期不足、测试集被调参读取，以及点时股票池缺少生效日期时都应失败。

## 观察结果

时间切分的主要价值是把“当时能看到什么”固定下来。它通常会让可用样本减少、实验周期变长，结果也可能比随机切分更不稳定；这不是理由去放宽约束，而是需要如实记录的研究成本。

## 结论边界

按时间切分和检查反未来函数只能降低最常见的信息泄漏风险，不能证明模型有效，也不能推出未来收益。下一篇可以讨论交易成本敏感性和结果稳定性。
