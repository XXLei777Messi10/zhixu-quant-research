# Research Note 0005：交易成本不是装饰——同一组信号在成本假设下如何变形

状态：公开研究基线，可复现合成实验

## 结论先说

同一组固定信号，在毛损益不变时，仅改变交易成本假设，净结果就会明显变化。成本不是回测报告末尾的一个装饰字段，而是研究结论的一部分。

本篇只讨论一个工程问题：如何把交易成本敏感性做成一个读者可以复跑、可以质疑、也可以替换参数的小实验。示例使用固定合成数据，不连接行情接口，不代表任何真实策略表现。

## 实验问题

如果信号和毛损益完全不变：

- 零成本假设会显示什么？
- 基准成本和压力成本会怎样改变净结果？
- 读者能否从输出中分辨毛损益、换手和成本，而不是只看到一个最终数字？

## 实验设置

`examples/cost_sensitivity.py` 固定了三组输入：

1. 五个合成事件的毛损益，单位为 bps：`42, -18, 36, -12, 28`。
2. 五个事件的名义换手率：`0.8, 0.6, 1.0, 0.4, 0.8`。
3. 三种每单位换手成本：零成本 `0 bps`、基准成本 `8 bps`、压力成本 `16 bps`。

这里的 bps 只是实验计量单位，不是任何账户或市场数据。实验明确写出 `live_data: false`，避免把示例误解成实时回测。

## 复现命令

在仓库根目录执行：

~~~bash
python examples/cost_sensitivity.py
~~~

预期输出：

~~~text
ZhiXu transaction-cost sensitivity demo
data_source: deterministic synthetic
status: ok
scenario       gross_pnl_bps  total_cost_bps  net_pnl_bps
zero_cost               76.0             0.0         76.0
base_cost               76.0            28.8         47.2
stress_cost             76.0            57.6         18.4
live_data: false
~~~

## 计算口径

实验只使用三个简单关系：

~~~text
gross_pnl_bps = sum(event_gross_pnl_bps)
total_cost_bps = sum(turnover) * cost_bps
net_pnl_bps = gross_pnl_bps - total_cost_bps
~~~

因此：

- 毛损益在三个情景中都为 `76.0 bps`。
- 总换手为 `3.6`。
- 基准成本为 `3.6 * 8 = 28.8 bps`。
- 压力成本为 `3.6 * 16 = 57.6 bps`。

输出把三项拆开，是为了让复核者能定位差异来自信号、换手还是成本参数。

## 失败实验：只展示毛损益

早期的最小示例只展示交易数量和模拟器是否运行。如果再进一步只展示毛损益，读者会看不到换手和成交假设，容易把一个未扣成本的中间量误读成策略结果。

这条路径被放弃，原因不是它不能运行，而是它不能回答公开研究最重要的复核问题：结论对交易成本是否敏感？

本篇保留三种情景，并把成本列放在输出中。这样即使读者不同意 `8 bps` 或 `16 bps`，也可以直接替换参数重跑。

## 反未来函数检查

本实验不使用日期、行情接口、模型预测或未来标签，只消费文件内固定的合成序列。因此它不能证明完整研究管线没有未来函数；它只证明这个成本敏感性 Demo 没有通过未来数据生成结果。

完整回测仍需遵守公开基线口径：第 T 日收盘后生成信号，最早按 T+1 日正式开盘价模拟成交，并单独检查特征、标签、切分和成交时间。

## 边界和下一步

本实验没有模拟佣金最低收费、印花税买卖方向差异、涨跌停、停牌、T+1、整数手、盘口冲击或成交失败。生产级或完整公开回测不能用这张表替代。

下一步可在保持输入快照不变的前提下，逐项加入：

- 买卖方向不同的税费；
- 最低佣金和整数手；
- 滑点与成交失败；
- 按时间段变化的成本参数；
- 成本参数的版本化和审计记录。
