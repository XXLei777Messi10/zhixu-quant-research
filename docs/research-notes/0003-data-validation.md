# Research Note 0003：先确认数据，再讨论模型

## 本篇问题

在 A 股日频横截面研究中，数据问题很容易被误认为模型问题。本篇建立一条公开、可复核的数据校验路径：单源结构校验、时间范围校验和独立来源交叉校验。

## 数据范围与截止日期

公开基线使用 AKShare 作为主要行情接口，并使用 Baostock 做独立交叉校验。仓库不分发第三方原始行情，因此每次复现都应记录：

- 数据供应商和接口版本
- 拉取日期与数据截止日期
- 复权口径
- 股票池口径
- 原始数据的请求或归档标识

实时接口可能发生字段变化、限流、历史修订或短时不可用。这些因素会让两次运行得到不同的数据快照。

## 方法

数据进入特征和标签计算前，依次检查：

1. 主键是否重复：来源、复权口径、股票代码和交易日应唯一。
2. OHLC 是否自洽：最高价不能低于开盘价、收盘价和最低价，最低价不能高于其他价格。
3. 交易状态是否明确：停牌和缺失不能自动当成零成交。
4. 价格、成交量和成交额是否满足基本范围。
5. 股票池和交易日历是否完整。
6. 相同口径的数据是否能与独立来源对齐。

校验报告应保存数据范围、行数、股票数、问题类型和严重级别，而不是只保存一个“成功/失败”标记。

## 时间切分

数据校验也必须遵守可见性边界。使用某个交易日生成信号时，只能使用该日收盘前后按研究协议明确可见的信息。后续修订的数据不能被悄悄覆盖进原始实验；应当通过新的 revision 重新运行，并保留旧报告。

## 交易成本与执行假设

本篇不评估收益。公开基线的执行口径仍要求单独记录：

- 信号在 T 日收盘后生成
- 最早在 T+1 日开盘模拟成交
- 考虑佣金、印花税、过户费和滑点
- 遵守停牌、涨跌停、T+1 和整数手限制

如果数据质量不通过，正确动作是停止生成新的模拟信号，而不是用插值、前值或零值把问题隐藏起来。

## 反未来函数检查

建议每次研究至少检查：

- 特征的最大可见日期不晚于信号日期
- 标签结束日期晚于信号日期，但不进入训练样本的可见部分
- 股票池使用点时成员关系，而不是事后成分股名单
- 行业映射和公司状态带有生效日期
- 复权数据的使用目的与成交价格口径分离

这些检查不能证明不存在所有未来函数，但可以把最常见的时间泄漏变成可审计的失败项。

## 观察结果

数据校验的价值不是让每次运行都“通过”，而是让失败可定位、可复现、可回滚。不同来源出现差异时，应该先记录差异的字段、行和相对大小，再决定是等待上游修复、隔离记录，还是调整口径。

## 失败实验或已知限制

一个常见失败做法是：发现少量异常后直接删除行，或者把缺失值填成零，让后续训练继续运行。这样会把数据问题变成不可见的模型偏差。

更安全的做法是使用带预期值和证据的隔离规则。只有当记录仍然匹配已验证的规则时才允许隔离；如果上游记录发生变化，规则本身应失效并触发硬失败。

本篇没有比较收益、准确率、IC、回撤或夏普比率，也不能据此判断任何策略优劣。

## 如何复现

先安装开发依赖，然后运行离线校验测试：

~~~bash
python -m pytest tests/test_validation.py -q
~~~

不需要 API 密钥，也不会访问实时行情接口。

## 结论边界

数据校验只能提高研究输入的可追溯性，不能证明模型有效，也不能保证回测结果稳定，更不能推出未来收益。下一篇计划讨论时间序列切分和隔离窗口。
