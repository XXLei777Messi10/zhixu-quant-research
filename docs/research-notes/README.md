# Research Notes

这里记录知序量研公开基线的研究方法、数据口径、失败实验和可复现性边界。

Research Notes 不发布收益承诺，也不代表生产模型或主账户的配置。每篇文章都应说明数据范围、截止日期、时间切分、交易成本、反未来函数检查和已知限制。

## 发布约定

- 每篇文章只回答一个明确的问题。
- 文章使用固定模板，便于读者复核。
- 失败实验可以发布，但必须说明失败原因或证据边界。
- 不公开 API 密钥、账户数据、生产配置、模型权重或内部路径。
- 不把历史模拟结果写成未来收益承诺。
