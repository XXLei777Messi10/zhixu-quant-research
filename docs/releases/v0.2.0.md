# v0.2.0 Public Model Release

状态：公开研究基线，可复现历史模拟；不是生产交易系统。

## 这次发布哪个模型

v0.2.0 对应：

~~~text
configs/rank_buffer_final_accounting_repair.yaml
run_id: rank-buffer-v4-locked-data-accounting-repair
candidate: weekly_top20_drop2_exit30_risk_mild_open
~~~

这是知序量研公开版在 v0.1.1 之后的第一版模型配置升级。它停留在较早的公开研究线，不包含主账户生产模型、v5 以后内部研究线、账户记录、历史预测或模型权重。

## 主要变化

- 保留 A 股日频横截面排序和每周调仓框架。
- 使用 Top20 候选池，并加入排名缓冲：排名跌出 30 名才具备退出资格，减少边界抖动。
- 信号在收盘后生成，最早按下一交易日开盘价进行模拟执行。
- 增加 walk-forward gap calibration 的轻量开盘过滤，用于识别开盘跳空和成本条件下不适合直接成交的情况。
- 保留佣金、印花税、过户费、滑点、停牌、涨跌停、T+1 和 100 股整数手等公开执行约束。
- 修复历史成分退出后的数据缺口，并修复调整股本后可能出现的账户份额残差。

## 与 v0.1.1 的关系

v0.1.1 继续作为简单、易读的基线版本保留。v0.2.0 的重点不是承诺更高收益，而是让“信号—订单—成交—净值”这条链条更接近可复核的模拟研究流程。

两版都不发布模型收益、超额收益、准确率、回撤、夏普比率或其他能力评估结果。使用者如需比较，应在相同数据快照、相同时间切分和相同交易成本下自行运行。

## 复现边界

本版本只支持历史研究和模拟交易，不连接券商、不发送真实订单、不构成交易依据。免费数据接口可能限流、改字段或修订历史数据，重新运行不保证得到完全相同的结果。仓库不分发第三方行情、账户数据、生产配置或内部模型文件。

完整配置见 [PUBLIC_BASELINE.md](../../PUBLIC_BASELINE.md)。代码入口见 [README.md](../../README.md)。

## 声明

本 Release 仅用于量化研究、软件工程演示和学术交流，不构成投资建议、证券推荐、收益承诺或交易依据。公开版与主账户生产模型不同；模型、数据和回测可能存在错误，历史模拟不代表未来表现。
